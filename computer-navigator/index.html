Computer Navigator

Version 0.4.0, alpha for Windows 11 x64

Lets an AI agent work in a browser and in Windows apps beside you, on screen where you can watch it and take over, without taking your focus and without ever seeing your passwords. Created by Tim Garrity.

Install

  1. Run the .msi, accept the licence, and leave "Open Computer Navigator setup" ticked on the last page.
  2. Or, for the zip: right-click it, choose Extract All, open the folder, and double-click "Install Computer Navigator".
  3. In the setup window choose your MCP clients (VS Code, GitHub Copilot CLI, Claude Desktop) and press Set up.
  4. Restart those clients so they load Computer Navigator.
  5. Leave "Open Windows Default Apps" ticked. On the Computer Navigator page that opens, press Set default once: it covers web links and local web pages (.html, .pdf), so they open in Computer Navigator instead of another browser. Windows lets only you make that choice.
  6. To see the browser yourself at any time, open "Computer Navigator Browser" from the Start menu.

The build is unsigned, so Windows SmartScreen may warn: choose More info, then Run anyway, and check the file against the SHA-256 above.
